Login Page Analysis

Two ways to capture login page data Choose whichever method works best for you. Both produce the same result.

Option 1: Bookmarklet (Recommended)

  1. Drag this button to your browser's bookmark bar:
IAM Login Analyzer
  1. Navigate to your application's login page
  2. Click the bookmarklet in your bookmark bar
  3. Copy the JSON that appears and paste it below

Option 2: Paste Page Source

  1. Navigate to your application's login page
  2. Right-click the page and select "View Page Source"
  3. Select all (Ctrl+A / Cmd+A), copy, and paste below
