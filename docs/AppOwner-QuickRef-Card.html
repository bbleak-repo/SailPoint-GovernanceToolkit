Disconnected App Data Feed -- Quick Reference

For application owners  |  Tape to monitor  |  Full guide: AppOwner-Integration-Guide.html
What to Deliver
When Daily by 04:00 UTC -- every day, even if nothing changed
File 1 accounts.csv  -- one row per user (ALL current users, not just changes)
File 2 entitlements.csv  -- one row per role, group, or permission
Account File Columns  (accounts.csv)
Column Name Req? Notes
id REQ Unique account identifier -- must be stable (not email)
name REQ Account username or login name
givenName REQ First name
familyName REQ Last name / surname
e-mail REQ Corporate email -- used for identity correlation. Case-sensitive column name: e-mail (with hyphen)
department REQ Business unit or department name
groups REQ Comma-separated role or group names. Wrap entire value in double quotes if multiple: "Role1,Role2"
IIQDisabled REQ Account enabled/disabled state: false = active, true = disabled. Use true/false -- not yes/no
accountType OPT e.g., Standard, Service, Admin
created OPT ISO 8601: 2024-01-15T09:30:00Z
lastLogin OPT ISO 8601 date-time of last authentication
Entitlement File Columns  (entitlements.csv)
Column Name Req? Notes
id REQ Unique entitlement ID -- must match values used in accounts groups column
name REQ Internal name of the role, group, or permission
displayName REQ Human-readable label shown to reviewers in certification campaigns
description REQ Plain-English description of what this entitlement grants. Helps reviewers make decisions.
owner OPT Email of the entitlement owner for escalation routing
type OPT e.g., Role, Group, Permission, Entitlement
riskLevel OPT Numeric 0-100 or LOW / MEDIUM / HIGH. Flags privileged items in reviews.
File Rules
  • - Encoding: UTF-8  -- in Excel choose Save As > CSV UTF-8 (Comma delimited)
  • - Delimiter: comma. Do not use semicolons or tabs.
  • - Header row required: exact column names are case-sensitive (e-mail not Email, IIQDisabled not iiqDisabled)
  • - Multi-valued groups: wrap the entire cell value in double quotes -- "AdminRole,ReadOnly,DataViewer"
  • - IIQDisabled values: true or false only -- not yes, no, 1, or 0
  • - Full export every time: never send only changed rows. SailPoint treats missing rows as deleted accounts.

Validate Before Go-Live
.\Scripts\Invoke-SPDisconnectedAppRegistry.ps1 -Action Test -AppName "YourApp"
  • +Required columns present and correctly named
  • +File encoding is UTF-8 (not UTF-16)
  • +No duplicate account IDs
  • +Email addresses match expected format
  • +Entitlement IDs cross-reference accounts groups column
Common Mistakes
  • X Excel default CSV is UTF-16, not UTF-8. Always use Save As > CSV UTF-8 (Comma delimited)
  • X Sending only changed rows. Always send the full population -- SailPoint treats missing rows as deleted accounts.
  • X Wrong column name casing. It must be e-mail (with hyphen), not Email or email.
  • X Sending an empty file when nothing changed. Still send the full export -- an empty accounts file removes all accounts.
