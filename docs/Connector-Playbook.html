Connector Playbook

This guide covers 20+ enterprise application connectors for SailPoint Identity Security Cloud (ISC). For each application: what connector is available, what it can do, what it costs, and what to watch out for.

All connectors are included with your ISC license -- SailPoint does not charge per connector. The constraint is your source limit (15 for Standard, 50 for Business, 200+ for Business Plus).

Key Concepts

The real cost is time, not money
For Tier 1 connectors, the biggest cost is configuration and testing time, not dollars. A Tier 1 connector with Express Setup can be in production in days. A custom connector takes months. Always check if a pre-built connector exists before deciding to build.

Directory and Authentication

The foundational identity sources -- Active Directory, Entra ID, Okta, and LDAP.

Microsoft Active Directory Included VA Required
Connector: VA-based (on-prem) Effort: 1-2 weeks Provisioning: Full CRUD
AggregationProvisioning Password MgmtGroups OUsDelta Aggregation

What it does: Manages AD user accounts, group memberships, OU placement, and passwords. Supports delta aggregation (only import changes since last run). The workhorse connector -- almost every ISC deployment starts here.

Key considerations:

  • Requires a VA cluster on-premise with network access to domain controllers
  • AD-synced groups in Entra ID are read-only from the Entra side -- manage them through this connector, not Entra
  • BeforeProvisioning rules are available (VA-based connector supports custom logic)
  • One source per AD domain; use Access Profiles to represent applications on top
Microsoft Entra ID (Azure AD) Included SaaS + VA Express Setup
Connector: SaaS (cloud-native) or VA-based Effort: 1-2 weeks Provisioning: Full CRUD
AggregationProvisioning Password MgmtGroups App AssignmentsB2B Guest Users MFA AttributesLicenses

What it does: Manages Entra ID users, groups, application assignments, B2B guest users, and licenses via Microsoft Graph API. Supports Conditional Access enforcement and token revocation.

Key considerations:

  • SaaS connector does NOT support BeforeProvisioning rules (VA-based does)
  • All Graph API Application permissions require admin consent regardless of read/write
  • Cloud-native groups only -- AD-synced groups must be managed via the AD connector
  • DELETE /groups/{id}/members/{userId}/$ref -- the /$ref is critical; omitting it deletes the user object
  • SAML token limit: 150 groups / JWT: 200 -- exceeding causes complete omission, not truncation
Okta Included SaaS + VA
Connector: SaaS (no VA needed) or VA-based Effort: 1-2 weeks Provisioning: Full lifecycle
AggregationProvisioning GroupsApp Assignments RolesDeprovisioning

What it does: Manages Okta Universal Directory users, groups, application assignments, and roles via Okta REST API. Automates provisioning and deprovisioning across the Okta ecosystem.

Key considerations:

  • In hybrid environments (Okta for SSO + SailPoint for governance), decide who is the authoritative provisioner
  • Okta group membership changes trigger SailPoint certification campaigns
  • Use SailPoint for governance/certification, Okta for authentication/SSO -- clear separation of duties
  • SaaS connector available (no VA required for cloud-only Okta deployments)
LDAP / OpenLDAP Included VA Required
Connector: VA-based Effort: 1 week Provisioning: Full CRUD
AggregationProvisioning Password MgmtGroups

What it does: Generic LDAP connector for any LDAP-compliant directory (OpenLDAP, Oracle Internet Directory, IBM Tivoli, Novell eDirectory, etc.).

HCM and HR Systems

Authoritative identity sources -- where employees and contractors are created, and lifecycle events (hire, transfer, terminate) originate.

Workday Included SaaS + VA Express Setup
Connector: 3 variants (HCM, Accounts, Students) Effort: 2-4 weeks Role: Authoritative source (JML)
AggregationDelta Aggregation Joiner/Mover/LeaverCustom Schemas Provisioning (Accounts variant)Student Accounts

What it does: The primary authoritative source for most enterprises. Workday HCM feeds employee/contractor identities into SailPoint, driving joiner, mover, and leaver lifecycle events. The Accounts variant adds provisioning back to Workday.

Key considerations:

  • Workday is typically the single source of truth for identity -- hire/transfer/terminate events flow from Workday to SailPoint to all downstream apps
  • Custom report-based integration: SailPoint reads from Workday custom reports (RaaS), not the standard Workday API
  • Plan 2-4 weeks for attribute mapping, custom reports, and lifecycle state configuration
  • Workday Accounts connector (separate from HCM) supports provisioning changes back to Workday
SAP HR/HCM + SuccessFactors Included SaaS + VA Express (SF)
Connectors: SAP HR/HCM (VA), SuccessFactors (SaaS+VA) Effort: 2-4 weeks Role: Authoritative source (JML)
AggregationDelta Aggregation Joiner/Mover/LeaverRead-only (HR/HCM) Provisioning (SuccessFactors)

What it does: SAP HR/HCM is a read-only connector for on-premise SAP HCM -- it feeds employee data into SailPoint as an authoritative source. SuccessFactors (cloud) supports full provisioning.

Key considerations:

  • SAP HR/HCM requires specific RFC authorization objects on the SAP admin user
  • For SAP access governance (roles, authorization objects), use the SAP Direct or SAP GRC connector (see ERP tab)
  • SuccessFactors LMS is a separate connector for learning management
ADP Workforce Now Custom / Third-Party
Native connector: None Effort: 4-8 weeks Options: Aquera bridge, custom build, flat file
No Native Connector

The situation: SailPoint does not have a pre-built connector for ADP Workforce Now. This is a notable gap given ADP's market share in payroll/HR.

Option A: Aquera Identity Bridge ($15K-40K/year estimated)

Third-party integration platform that synchronizes ADP worker data with SailPoint. Available on the ADP Marketplace. Handles the API integration, attribute mapping, and delta sync. Fastest path to production (2-3 weeks).

Option B: Custom SaaS Connector via ADP API Central ($15K-60K one-time)

Build a custom connector using SailPoint's SaaS Connectivity SDK (TypeScript) that calls ADP API Central endpoints. Gives you full control but requires development and ongoing maintenance when ADP changes their API.

Option C: Flat File / Delimited File ($0-5K + ongoing manual effort)

Export a CSV from ADP and feed it to SailPoint via the Delimited File connector. Simplest to set up but requires either manual export or a MuleSoft/GoAnywhere pipeline to automate the daily delivery. Read-only governance (no provisioning back to ADP).

Recommendation
For organizations with 1,000+ identities in ADP, the Aquera bridge (Option A) offers the best ROI. For smaller environments or budget constraints, the flat file approach (Option C) with MuleSoft/GoAnywhere automation is pragmatic.

ERP and Finance Systems

Complex, high-value targets for identity governance. SAP and Oracle deployments often have the most intricate access models.

Connectors: 10+ SAP-specific connectors Effort: 4-8 weeks (SAP is complex)
AggregationProvisioning SoD ChecksRole Management Authorization ObjectsGRC Integration

SAP Direct (VA-based)

Connects directly to SAP ECC/R3 via RFC. Manages users, roles, profiles, and authorization objects. The most common SAP connector for ERP access governance.

SAP S/4HANA Cloud (SaaS + VA, Express Setup)

For organizations on S/4HANA Public Cloud. Supports user creation, role assignment, and full CRUD operations via API.

SAP GRC (VA-based) Requires SAP GRC License

Integrates with SAP Governance, Risk and Compliance for SoD (Separation of Duties) checks during provisioning. Provisioning requests go through GRC approval workflows. Requires SAP GRC to be licensed and configured on the SAP side.

Key considerations:

  • SAP access models are deeply nested (roles contain profiles contain authorization objects) -- plan for complex entitlement modeling
  • SoD checks are critical for compliance -- integrate with SAP GRC or SailPoint's native SoD
  • SAP HR/HCM (authoritative source) and SAP Direct (access governance) are separate connectors that serve different purposes

Building Custom Connectors

When no pre-built connector exists, here are your options -- from zero-code to full development.

SaaS Connectivity SDKDevelopment Required
Language: TypeScript/JavaScript Effort: 2-6 weeks Cost: $15K-60K (PS) or internal dev time

The recommended path for modern cloud apps with REST APIs. Build a connector using SailPoint's open-source SDK (sp-connector-sdk-js on GitHub). Develop, debug, and test locally. Deploy to SailPoint's cloud infrastructure (no VA needed).

Best for: SaaS apps with REST APIs, no pre-built connector, need full provisioning.

Ongoing cost: You maintain the connector. API changes from the target app require updates.

Connector Studio (Beta)Included (No Code)
Language: Visual builder (no code) Effort: 1-2 weeks Cost: $0 (included with ISC)

Launched April 2025 in beta. Build connectors visually by mapping attributes and defining rules without writing code. Rolling out to enterprise tenants. Best for simple REST API integrations where you need basic aggregation and provisioning.

Web Services ConnectorIncluded
Language: Configuration (XML/JSON) Effort: 1-3 weeks Cost: $10K-40K (PS)

Generic connector that can call any REST or SOAP API via configuration (no code). Define endpoints, authentication, request/response mapping in the ISC admin UI. Available as both SaaS and VA variant.

Best for: Apps with standard REST/SOAP APIs where you need aggregation + basic provisioning.

JDBC ConnectorIncludedVA Required
Effort: 1-2 weeks Cost: $5K-20K (PS)

Direct database connectivity via JDBC. Write SQL queries to extract accounts and entitlements. Supports provisioning (INSERT/UPDATE/DELETE). Requires VA with network access to the database.

Best for: Legacy apps with no API but accessible database. Common for line-of-business applications built on SQL Server, Oracle, or MySQL.

Delimited File ConnectorIncludedSaaS + VA
Effort: Days Cost: $0-5K + pipeline maintenance

Read account and entitlement data from CSV files. The simplest integration option. No provisioning (read-only governance). Requires a pipeline to produce and deliver daily files (see the App Owner Integration Guide for MuleSoft/GoAnywhere patterns).

Best for: No API, no DB access, or apps where you need governance quickly while planning a deeper integration.

The 80/20 rule
Most organizations get 80% of their governance coverage from 5-8 connectors: Active Directory + Entra ID + Workday (or SAP HR) + Salesforce + ServiceNow + 1-2 industry-specific apps. Start there, then expand incrementally.
