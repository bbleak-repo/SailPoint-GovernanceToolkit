### State tracking (SP.EntitlementState / SP.ReviewerState / SP.StateOrchestrator)
Did not work as shipped: reviewer state NEVER populated (processedInstances
ownership bug), a same-day rerun flipped every record out of scope, ACTIVE
campaigns froze at their first mid-day snapshot (reviewers permanently
"Missed"), the `, $array` reader idiom wasn't flattened so **all state records
keyed to blank strings against the real cache**, writes were non-atomic
(delete-then-rename, shared tmp name), day keys had no year, reviewers were
keyed by display name, corrupt files silently reset months of history.
All fixed in commit `46b8922` — see the v2.1 ownership contract in the module
headers. 136 module tests + 7 new orchestrator integration tests
(`Tests/SP.StateOrchestrator.Tests.ps1`) cover every failure mode.
