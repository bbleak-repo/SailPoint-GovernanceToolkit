Access Review Decision Guide

Follow this flowchart for each item in your certification campaign
Key: Question Approve Revoke Reassign Not Sure -- investigate first
START: You received an access review for a team member
Question 1
Is this person still on your team?
NO
REASSIGN
Forward to their current manager -- they know this person's current role.
YES
continue
Question 2
Do you recognize this system or permission?
NO
REASSIGN
Send to the system owner, or ask the team member whether they use it before deciding.
YES
continue
Question 3
Does this person actively use this access for their CURRENT job?
Check Last Activity date in ISC if you are unsure
NO
REVOKE
Comment: "No longer needed for current role." Remove it now; it can be re-requested if needed.
NOT SURE
INVESTIGATE FIRST
Ask: "What do you use [system] for?" or check Last Activity date in ISC.
Then return to Question 3 with your answer.
YES
continue
Question 4
Is this elevated or privileged access?
Look for a PRIVILEGED flag or admin-level entitlement name
NO
APPROVE
Routine access confirmed. No comment required -- click Approve and move on.
YES, PRIVILEGED
continue
Question 5
Is there a lower-level permission that would cover this person's needs?
Least-privilege principle: grant only what is required, nothing more
YES
REVOKE
Over-privileged. Revoke this level, then work with the IAM team to request the correct entitlement.
NO
continue
Question 6
Is this a permanent ongoing need, or time-limited?
Project-based or temporary roles are common examples of time-limited access
TIME-LIMITED
APPROVE
Approve with a comment stating the expected end date or project completion milestone. Flag for follow-up review.
PERMANENT
APPROVE
Comment: explain the business reason why this elevated access is required on an ongoing basis.
